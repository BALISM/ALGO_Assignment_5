💡 Question Requirement: Does BFS Guarantee a Minimum-Cost Path?

Answer: NO. BFS guarantees the minimum number of hops (moves), which here is 15 moves. However, because edge costs vary (-3 to +3) and the graph contains negative-cost cycles (e.g. Up-Left [-3] + Right [+2] + Down [-1] = -2), a path with more moves can have a lower total cost. The BFS path costs 51, whereas the DFS reverse-order path costs only 34.

💡 Question Requirement: Successor Ordering & Non-Optimality of DFS

DFS returns the first path it encounters without evaluating alternative costs. In our ordering experiment: Default order costs 68 (40 moves); Goal-ward order costs 75 (42 moves); Reverse order costs 34 (78 moves). The path cost fluctuates dramatically (>2x), proving DFS cannot guarantee optimality.
